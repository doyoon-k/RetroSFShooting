# Stage 01 — 유도하고, 길을 열고, 돌파하기

2026-09-27 구현 기준. 아래 수치는 이 프로젝트용 **사용자의 「너무 쉽다」 피드백을 반영한 두 번째 밸런스**이다. 논문이나 다른 게임이 보장하는 최적값이 아니다. 실제 배치는 `scenes/gameplay/stage/stage_01.tscn`이 기준이다. 기존 Enemy 폴더의 S/M/L 스프라이트를 사용한다.

## 무엇을 재미의 중심에 둘 것인가

플레이어가 **발사 예고를 보고 조준탄을 한쪽으로 유도 → 빈 높이로 이동 → 먼저 잡을 적을 선택 → 쉬운 편대를 연속 격추**하는 순환을 만든다. 공격해서 위험을 줄일 수 있어야 한다. 기존 근접 피해 보너스와 직선/확산 무기 변경을 이 선택에 연결한다.

현재는 **61개 편대 144기 + 직접 배치 2기 = 146기**, 스크롤 156초다. 첫 개편의 132기 대부분은 무발사 편대였고, 공격 중첩이 부족했다. 이번에는 노멀 사격 적 14기를 추가해 상하단의 서로 다른 공격이 겹치도록 했다.

### 첫 밸런스가 쉬웠던 이유와 수정

동일한 LV3 직선 자동 사격에서 이전 미들은 4.0~4.98초에 죽었다. 스크롤 진행 중 최근 2초 안에 서로 다른 두 적이 발사한 시간 비율도 4.2%뿐이었다. 이전의 532개 통과는 기능 테스트였고 실제 난이도 검증으로 볼 수 없다.

- N1~N5 HP를 6/10/14/20/12 → **12/24/32/44/26**으로 조정했다. LV3 직선의 이론 DPS 25 기준 약 0.48/0.96/1.28/1.76/1.04초의 명중 시간이 필요하다. 실제로는 접근·탄 비행·빗나감이 더해진다.
- N1은 205→245로 빠르게 통과하고, N2는 170→125, N4는 100→90, N5는 150→130으로 오래 남아 사격한다. 같은 속도 배율을 일괄 적용하지 않았다.
- 일반 사격 적의 최초 대기를 0.7→0.35초로 줄였다. 화면 안 진입 후 예고 0.35초를 더해 첫 탄은 최소 약 0.7초 뒤 나온다. 노멀을 공격 전에 잡는 플레이는 여전히 가능하다.
- 조준 2연사→2연사, 짧은 연사 3→4발, 부채꼴 3→5발/52°, 유도탄 1→2발. 회복 시간도 각 역할에 맞춰 단축했다.
- 미들 HP는 M2/M1/M3 **220/240/260**, 보스 **520**. M2는 LV1 명중 손실로 교전이 늘어져 왕복 진폭을 190→150, 주파수를 0.12→0.10Hz로 낮췄다.
- 예고, 화면 밖 발사 제한, 유도 시간 제한은 유지한다.

직선 무기의 이론 원거리 DPS는 LV1 12.5, LV3 25이며 근접하면 최대 2배다. 보스 520 HP의 전탄 명중 시간은 LV1 41.6초, LV3 20.8초다. 실제 시간은 움직임과 탄 비행에 따라 더 길다. 확산 무기는 원거리 단일 표적에 중앙 탄만 맞는 경우가 많으므로 큰 적에서는 H로 직선 전환하는 것이 유리하다. 확산만 유지하는 조건은 별도 진단으로 분리한다.

## 공격의 공정성과 읽기

- 모든 공격 묶음 시작에 기본 0.35초 노란 수축 고리로 예고한다. `Shooter.telegraph_seconds`로 조절한다. 조준 2연사·부채꼴·연사는 예고 시작 위치를 겨냥한다. 탄이 나온 뒤 이동하면 피해 갈 수 있다.
- 총구가 전투 영역 안쪽 32px에 들어와야 쏜다. 일반 적은 플레이어 뒤쪽 80px 이내이거나 총구와 160px 미만이면 발사를 보류한다. 미들·보스에는 근접 억제를 적용하지 않는다.
- 예고 도중 화면 밖으로 나가면 취소하고 다시 예고한다. 공격 리소스에는 런타임 타이머를 저장하지 않는다.
- 유도탄은 최초 1.2초만 0.65rad/s로 방향을 바꾼 뒤 직진한다. 되돌아오는 추적 부담을 줄인다.
- 링 탄을 적 보라색과 구분되는 밝은 노란색으로 바꿨다. 회전탄은 4방향×8회, 0.20초 간격, 회복 1.6초다.
- 이 규칙들은 화면 밖 기습을 줄이는 장치다. 모든 상황의 무피격 경로를 증명한 것은 아니다. 특히 마지막 N2/N5/Z4 조합은 인간 테스트 우선 대상이다.

비교 가능한 이전 LV3 직선 조건: 중첩 4.2%, 미들 4.15/4.00/4.98초, 보스 16.30초. 최종 조정에서 중첩은 26.0%로 증가했다. 노멀 사격 적 중 격파 전에 한 발도 못 쏜 비율은 8/24 → 9/33이다. 빠른 선제 격파로 공격을 줄이는 여지는 남아 있다. 계측 결과를 인간에게 적합한 최종 난이도의 증거로 취급하지 않는다.

확산만으로 큰 적까지 공격하는 추가 진단에서는 교전이 지나치게 길어지는 약점이 확인됐다. 이번 목표는 K 전환을 포함한 플레이이며, 확산 단독 보스 화력을 직선과 같게 조정하지 않았다. 확산 고정 플레이도 지원하려면 별도의 무기 밸런스 검토가 필요하다. 기능 회귀 검사 560개 통과.

`tests/stage_balance_probe.gd`는 정상 속도, 실제 탄 충돌 피해·드롭, 무적 플레이어, 자동 사격으로 한 번 끝까지 진행한다. 일반 구간에서는 위아래로 이동하고 미들·보스는 높이를 따라간다. 폭탄은 쓰지 않는다. **목적은 진행 막힘·교전 길이·동시 오브젝트 계측이며 회피 실력이나 인간의 재미를 흉내 내지 않는다.**

계측은 LV1/LV3을 매 프레임 고정하고 직선 유지 또는 일반 구간 확산·미들/보스 직선 전환으로 나눈다. 강화 미획득 상태를 보상으로 덮지 않기 위해 레벨을 고정한다. `--power1`, `--power3`, `--mixed`, `--spread` 옵션을 사용한다.

`two_source_window_percent`는 스크롤 진행 중 최근 2초 이내 서로 다른 적 둘 이상이 발사한 시간의 비율이다. 이미 죽은 적이 쏜 탄의 잠재적 잔류도 포함한다. 정확한 탄 경로 중첩 면적이나 피할 수 있는 공간의 비율이 아니다. `bullet_contacts_075_cooldown`은 무적 봇과 탄이 실제 접촉한 횟수에 0.75초 간격을 적용한 계측이며, 잔기 소모나 생존 가능성을 의미하지 않는다. 봇은 탄 회피를 하지 않는다.

재현: `godot --headless --path . --script tests/stage_balance_probe.gd --fixed-fps 60 -- --power3 --mixed`. JSON은 `build/validation/stage_balance_lv3_mixed.json` 등 조건별 파일에 저장한다.

### 사람에게 확인할 순서

1. 초보 플레이어가 공략 설명 없이 2회 플레이. 사망한 스크롤 초, 적 종류, 사망 이유를 설명할 수 있는지 기록한다.
2. 7초·17초 강화 적을 알아보고 격파하는지 확인한다. 못 알아보면 보상 적 표식을 추가하거나 위치를 조정한다. 탄속을 먼저 바꾸지 않는다.
3. 47–64초 구간에서 위/아래 선택이 생기는지, 137–141초에 도망갈 곳이 없다고 느끼는지 확인한다. 후자는 N5 또는 Z4를 1초 늦추는 것부터 실험한다.
4. 미들전 목표는 LV3 10–18초, LV1 15–28초, 보스는 LV3 25–40초 / LV1 40–60초. 적을 오래 못 맞춰 늘어지면 진폭부터 줄이고, 잘 맞추는데 늘어지면 HP를 10%씩 줄인다.
5. LV1로 복구 중인 플레이, 확산 무기, 폭탄 사용, 강화 전부 획득의 네 조건을 따로 확인한다. 최강 상태만으로 난이도를 결정하지 않는다.
6. 조준을 유도하는 선택이 체감되면 유지. 예고가 안 보이면 밝기/크기/0.35→0.45초를 먼저 실험한다. 어려움 해결용으로 전체 적을 한꺼번에 느리게 만들지 않는다.

F6 Enemy Lab은 개별 적/이동/공격을 바꿔 확인하는 용도다. 실제 조합은 Stage01의 Wave 마커에서 `Movement Profile`, `Attack Sequence`, `Spawn Offset`을 바꿔 확인한다. `hold_high.tres`, `hold_low.tres`가 이번에 추가된 높이별 이동 프리셋이다. 아래 상세 배치표는 구현 스냅샷이며 씬 수정 뒤 함께 갱신한다.
